# 지원포유 콘텐츠 스튜디오

> "제미나이, 클로드 등 AI 도구 소개 및 기본사용법부터 1인 가구·프리랜서·직장인이 활용하는 방법을 지원포유에서 알려드립니다."

구글 블로거 · 네이버 블로그용 **돈 되는 주제 발굴 → 원고·이미지 생성 → 비공개 발행 → 사람 검수 → 공개 발행 → 카드뉴스·SNS 확산 → 유입·수익 분석 → 발전 제안**까지 한 대시보드에서 처리하는 시스템입니다.

```
 ┌──────────┐   ┌──────────────┐   ┌─────────────┐   ┌──────────┐   ┌──────────┐
 │ 주제 발굴 │ → │ 원고+이미지  │ → │ 비공개 발행 │ → │ 사람 검수 │ → │ 공개 발행 │
 │ (점수화)  │   │ SEO/AEO/GEO  │   │ 블로거 초안 │   │ 체크리스트│   │          │
 └──────────┘   │ 자동 점검    │   │ 네이버 비공개│   │ 편집·승인 │   └────┬─────┘
       ▲        └──────────────┘   └─────────────┘   └──────────┘        │
       │                                                                  ▼
 ┌──────────┐   ┌──────────────────────────┐   ┌────────────────────────────────┐
 │ 발전 제안 │ ← │ 유입·수익 분석            │ ← │ 카드뉴스 → 인스타·스레드·페북  │
 └──────────┘   │ GA4·서치콘솔·애드센스·CSV │   └────────────────────────────────┘
                └──────────────────────────┘
```

## 주요 기능

| 영역 | 내용 |
|---|---|
| **주제 발굴** | 네이버·구글 자동완성 → 롱테일 확장, 네이버 검색광고 API(월간 검색량·광고 경쟁도=CPC 단가), 블로그 문서 수(포화도), 데이터랩 트렌드, 구글 트렌드를 종합해 **검색량·경쟁·수익성·트렌드·주제 적합도** 점수화. AI가 제목·관점·독자(1인 가구/프리랜서/직장인)를 기획 |
| **원고 생성** | Claude(기본) 또는 Gemini. 작성 전 **웹 검색으로 최신 요금제·기능 조사** → 플랫폼별 가이드(네이버 C-Rank·D.I.A+·AI 브리핑 / 구글 E-E-A-T)에 맞춰 구조화된 원고 생성. 계정별 콘셉트 반영, 이미 쓴 글과 겹치지 않게 작성 |
| **SEO·AEO·GEO** | 상단 직답·핵심요약·질문형 소제목·FAQ(AEO), 기준일·공식 출처·비교표·프롬프트 예시·저자 엔티티(GEO), 키워드 배치·분량·이미지 alt·메타 설명(SEO). 블로거에는 **Article/FAQPage 구조화 데이터**·목차 자동 삽입. **20여 개 항목 자동 점검 점수** 제공 |
| **이미지** | 썸네일(제목 합성, 네이버는 1:1) + 본문 이미지: 공식 사이트 **화면 캡처**, Gemini **AI 이미지 생성**, Unsplash/Pexels **스톡 검색**, 실패 시 브랜드 템플릿. 검수자가 **직접 캡처로 교체** 가능 |
| **발행** | 1단계: 블로거 **초안(isDraft)** / 네이버 **비공개 발행 또는 임시저장** → 2단계: 사람 승인 후 공개. 블로거는 공식 API, 네이버는 Playwright 브라우저 자동화 |
| **유사문서 방지** | 모든 원고 간 유사도 계산, 35% 이상이면 경고 (여러 계정 운영 시 필수) |
| **수익화** | 애드센스 인아티클 광고 슬롯 자동 삽입(블로거), 쇼핑커넥트·쿠팡파트너스 상품 라이브러리 → 관련 있을 때만 1~2개 자연 삽입 + **대가성 문구 자동 표기** |
| **카드뉴스** | 원고 → 7장 카드뉴스(1080×1350) + 인스타·스레드·X·페이스북·밴드용 캡션. 문구 편집 후 재렌더, 테마 3종. 인스타그램·스레드·페이스북 자동 발행, 그 외는 ZIP |
| **분석** | GA4(글별 조회수), 서치콘솔(클릭·노출·순위·검색어), 애드센스(일별 수익) 자동 동기화. 네이버는 RSS로 공개 여부 확인 + 조회수·애드포스트·쇼핑커넥트 **CSV/직접 입력**. 계정별 RPM |
| **발전 제안** | 규칙 기반(제목 개선·2페이지 글 보강·수익화 누락·카드뉴스 재활용·발행 주기·검수 적체·검색어 공백 → 다음 주제) + AI 전략 요약 |
| **멀티 계정** | 블로거 N개(계정마다 다른 구글 아이디 가능)·네이버 N개·SNS N개. 계정별 콘셉트·광고 설정·분석 설정 |
| **자동화** | 워커가 매주 주제 발굴, 매일 분석 동기화·발전 제안 갱신 (cron 설정 가능) |

## 빠른 시작 (데모 모드 — API 키 없이 체험)

필요: **Node.js 22 이상**

```bash
npm install
npx playwright install chromium     # 썸네일·카드뉴스 렌더링, 네이버 자동화용 브라우저
cp .env.example .env
npm run setup                        # DB 생성 + 브랜드 설정·데모 계정·샘플 제휴상품
npm run dev                          # 웹(3000) + 워커 동시 실행
```

http://localhost:3000 접속 → **주제 발굴 → 원고 생성 → 비공개 발행 → 승인 → 공개 발행 → 카드뉴스 → 분석 동기화 → 발전 제안**을 샘플 데이터로 모두 눌러볼 수 있습니다.
`[데모]` 계정은 실제 플랫폼에 발행하지 않고 상태만 바뀝니다.

> 이미 설치된 크롬을 쓰려면 `.env` 에 `CHROMIUM_EXECUTABLE_PATH` 를 지정하면 `playwright install` 없이도 동작합니다.

## 실제 운영 설정

`.env` 에 필요한 키를 넣고 재시작하면, 키가 있는 기능부터 자동으로 실제 모드로 바뀝니다. 대시보드 **[설정]** 에서 연동 상태를 확인할 수 있습니다.

### 1) 글쓰기 AI (필수)
- **Claude**: https://console.anthropic.com → API 키 → `ANTHROPIC_API_KEY` (기본 모델 `claude-opus-5`, 원고 전 웹 검색으로 사실 확인)
- **Gemini**: https://aistudio.google.com → API 키 → `GEMINI_API_KEY` (Google 검색 그라운딩, **이미지 생성**에도 사용)
- 둘 다 넣으면 글은 Claude, 이미지는 Gemini 를 씁니다. `LLM_PROVIDER` 로 강제 지정 가능.

### 2) 주제 발굴 데이터 (강력 권장)
- **네이버 개발자센터** (https://developers.naver.com) → 애플리케이션 등록 → 검색·데이터랩(검색어트렌드) 사용 → `NAVER_CLIENT_ID/SECRET`
- **네이버 검색광고 API** (https://searchad.naver.com → 도구 → API 사용관리) → `NAVER_AD_API_KEY/SECRET_KEY/CUSTOMER_ID`
  월간 검색량과 **광고 경쟁도(= 광고 단가)** 를 가져와 "돈 되는 키워드"를 판별하는 핵심 데이터입니다.
- 키가 없으면 자동완성 + 휴리스틱으로 점수화합니다.

### 3) 구글 블로거 · GA4 · 서치콘솔 · 애드센스
1. Google Cloud Console 에서 프로젝트 생성 → **Blogger API v3, Google Analytics Data API, Search Console API, AdSense Management API** 사용 설정
2. OAuth 동의 화면 구성(테스트 사용자에 본인 구글 계정 추가) → OAuth 클라이언트 ID(웹 애플리케이션)
3. 승인된 리디렉션 URI: `{PUBLIC_BASE_URL}/api/oauth/google/callback`
4. `.env` 에 `GOOGLE_CLIENT_ID/SECRET` → 대시보드 **[계정 관리] → 블로거 계정 추가 → [구글 연결]**
5. 계정 설정에 애드센스 게시자 ID·인아티클 슬롯 ID(선택), GA4 속성 ID, 서치콘솔 속성 URL 입력

> 블로거 API 는 **이미지 업로드를 지원하지 않습니다.** 이미지를 외부에서 볼 수 있어야 하므로 `IMAGE_HOST=cloudinary`(무료 플랜 가능)를 권장합니다. 서버를 인터넷에 공개했다면 `PUBLIC_BASE_URL` 만으로도 됩니다.
> 블로거 API 로는 **검색 설명(메타 설명)** 을 넣을 수 없어, 검수 화면의 메타 설명을 블로거 편집기의 "검색 설명"에 붙여 넣어 주세요.

### 4) 네이버 블로그 (브라우저 자동화)
네이버는 블로그 글쓰기 공개 API 가 없어(2020년 종료) Playwright 로 스마트에디터 ONE 을 조작합니다.
1. [계정 관리] 에서 네이버 계정 추가 (외부 ID = 블로그 아이디)
2. **화면이 있는 PC**에서 한 번 로그인 → 세션 저장 (아이디/비밀번호 자동 입력은 하지 않습니다)
   ```bash
   npm run naver:login -- <계정ID>     # 계정ID 는 [계정 관리] 카드 하단에 표시
   ```
3. 계정 설정에서 1단계 발행 방식 선택: **비공개 발행**(기본) 또는 **임시저장**
4. `NAVER_HEADFUL=1` 이면 자동화 과정을 브라우저 창으로 볼 수 있습니다. 실패 시 `storage/naver/debug-*.png` 에 화면이 저장됩니다.

### 5) SNS (카드뉴스 자동 발행)
- **인스타그램**: 비즈니스/크리에이터 계정 + 페이스북 페이지 연결 → Meta 앱에서 장기 액세스 토큰 발급 → [계정 관리]에 IG 사용자 ID·토큰 입력
- **스레드**: Threads API 토큰·사용자 ID / **페이스북 페이지**: 페이지 ID·페이지 토큰
- 틱톡·밴드·카카오채널 등은 **ZIP 다운로드(이미지+캡션)** 로 올립니다.

### 6) 보안
- `DASHBOARD_PASSWORD` 를 설정하면 대시보드 전체에 로그인(Basic Auth)이 걸립니다. 서버를 외부에 공개한다면 **반드시** 설정하세요. (`/media` 이미지 경로만 공개)
- 계정 토큰은 `APP_SECRET` 기반 AES-256-GCM 으로 암호화해 저장합니다. `APP_SECRET` 은 한 번 정하면 바꾸지 마세요.

## 하루 운영 루틴 (권장)

1. **대시보드** → 검수 대기 원고 확인
2. 원고 화면에서 **SEO·AEO·GEO 점수**의 ⚠️ 항목과 **검수 체크리스트** 확인
   - 요금·기능 수치 최신 여부, **직접 캡처 화면으로 교체**, 내 경험 한 문단 추가 (네이버·구글 모두 경험 기반 독창 콘텐츠를 우대합니다)
3. [원고 편집] 탭에서 수정 → 저장하면 점수 재계산 → **비공개 발행 → 승인 → 공개 발행**
4. 반응 좋은 글은 **카드뉴스**로 SNS 확산
5. 주 1회 **발전 제안**의 실행 과제 처리 (제목 개선, 글 보강, 제휴 상품 추가)
6. 월말에 애드포스트·쇼핑커넥트 수익을 **CSV 가져오기**로 반영

## 여러 계정 운영 팁
- 계정마다 **콘셉트를 다르게** 쓰세요 (예: 네이버A = 직장인 업무 자동화, 네이버B = 1인 가구 생활 AI, 네이버C = 프리랜서 수익화). 같은 주제로 여러 계정 원고를 만들면 콘셉트에 맞춰 다른 관점으로 작성되며, 유사도 35% 이상이면 경고합니다.
- 같은 주제를 여러 네이버 계정에 **같은 날 동시에** 올리는 것은 피하세요.
- 블로거는 계정마다 다른 구글 아이디로 연결할 수 있습니다.

## 폴더 구조

```
prisma/schema.prisma        데이터 모델 (계정·주제·원고·자산·카드뉴스·지표·수익·제안·작업)
scripts/worker.ts           백그라운드 워커 + 스케줄러
scripts/naver-login.ts      네이버 로그인 세션 저장
src/lib/topics/             주제 발굴 (수집 sources / 점수 scoring / 기획 discover)
src/lib/content/            원고 (프롬프트·스키마·생성·렌더링·SEO 점검·유사도)
src/lib/images/             이미지 소스·썸네일·외부 호스팅
src/lib/cardnews/           카드뉴스 기획·렌더링·ZIP
src/lib/publishers/         블로거(API)·네이버(Playwright)·SNS(Graph API)
src/lib/analytics/          GA4·서치콘솔·애드센스 동기화, CSV, 집계
src/lib/insights/           발전 제안 엔진
src/app/                    대시보드 화면 + API
tests/                      단위 테스트 (npm test)
storage/                    생성 이미지·네이버 세션 (git 제외)
```

## 배포
- 워커(Playwright 포함)가 항상 돌아야 하므로 **상시 켜진 PC 또는 VPS**(예: 2vCPU/4GB)에 `npm run build && npm start` 로 운영하세요.
- 운영 DB 는 PostgreSQL 권장: `prisma/schema.prisma` 의 provider 를 `postgresql` 로 바꾸고 `DATABASE_URL` 변경 후 `npm run db:push`.
- 네이버 로그인(`naver:login`)은 화면이 필요하므로 로컬 PC에서 실행한 뒤 `storage/naver/<계정ID>.json` 을 서버로 복사해도 됩니다.

## 알려진 제약 · 주의사항
- **네이버 자동화는 실제 네이버 계정으로 검증이 필요합니다.** 네이버 에디터 구조가 바뀌면 `src/lib/publishers/naver.ts` 의 `SELECTORS` 를 수정해야 할 수 있습니다. 실패해도 원고는 남아 있으므로 [HTML 코드]를 복사해 수동 발행 후 **[직접 발행함으로 표시]** 를 누르면 분석이 이어집니다.
- 네이버 블로그 통계·애드포스트·쇼핑커넥트는 공개 API 가 없어 **CSV/직접 입력**으로 반영합니다.
- AI 원고는 초안입니다. 대량 자동 발행은 네이버 저품질·구글 스팸 정책 위험이 있어 **사람 검수 후 공개**하도록 설계했습니다 (승인 없이 공개 발행 불가).
- AI 도구의 요금·기능은 자주 바뀝니다. 원고의 `reviewChecklist` 와 출처를 꼭 확인하세요.
